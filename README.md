# 🏰 蛋仔宫殿大冒险

一个蛋仔派对风格的 Three.js 3D 跑酷游戏。

## 📁 目录结构（模型这样放）

```
eggy-game/
├── index.html          ← 游戏本体
├── README.md
└── models/
    ├── character.glb   ← 你的蛋仔角色模型（命名成这个）
    └── scene.glb       ← 你的卡通宫殿场景模型（命名成这个）
```

> 模型必须是 **GLB / GLTF** 格式。没有放模型也能玩——游戏会自动用程序生成的蛋仔和宫殿兜底。
> 如果模型是 FBX/OBJ 格式，先用 Blender 打开，「文件 → 导出 → glTF 2.0 (.glb)」转换。

## ▶️ 运行方式

由于浏览器安全限制，需要通过本地服务器打开（不要直接双击 html）：

```bash
cd eggy-game
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

或者用 VS Code 的 Live Server 插件：右键 index.html → Open with Live Server。

## 🎮 玩法

| 操作 | 按键 |
|------|------|
| 移动 | WASD 或 方向键 |
| 跳跃 | 空格 |

- 沿着粉色浮台一路向宫殿方向跑，吃金币（每枚 +10 分，共 8 枚）
- 小心**红色旋转锤**，碰到或掉下平台会扣一条命（共 3 条 ❤️）
- 抵达宫殿门口的黄色终点平台即通关 🎉

## ✨ 特效清单

- 梦幻渐变天空 + 环境反射 + 雾效
- 软阴影 + ACES 电影级色调映射
- 蛋仔跑动时的 Q 弹挤压动画（squash & stretch）
- 吃金币金色粒子爆炸、受伤红色粒子、无敌时间闪烁
- 移动/升降平台、旋转金币、漂浮云朵、卡通描边平台
- 第三人称平滑跟随相机

## 🔧 常见问题

| 问题 | 解决 |
|------|------|
| 黑屏/一直加载 | 检查是否用 http 服务器打开（不能 file:// 直接双击） |
| 模型不显示 | 确认路径是 `models/character.glb`，且是 GLB 格式 |
| 模型太大/太小 | 代码已自动缩放，如仍异常可在 Blender 里先归一化尺寸 |
| 方向反了 | 在 Blender 导出时勾选 +Y up |
